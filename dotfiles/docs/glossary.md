# Glossary

Words the user wants and words they don't. Read it before naming anything:
a variable, a function, a class, a concept in a PR description. Entries are
recorded with the `adrien-record-preference` skill.

Each entry has this shape:

```
## <the word to use>

<what it means, in one sentence>

- don't use: <the words the user rejected>
- why: <the user's reason>
- scope: all repos, or the one repo it applies to
```
