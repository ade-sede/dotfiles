# Patterns

Code the user liked and code they disliked, copied from real changes, with
the reason. The `adrien-coding-style` skill holds the rules; this file
holds the cases behind them. Entries are recorded with the
`adrien-record-preference` skill.

Each entry has this shape:

````
## <the pattern, named in a few words>

```<language>
<the snippet, 20 lines at most>
```

- why: <the user's reason>
- scope: all code, one language, or one repo
````
